## How the config (system) work?
A config is created from 3 things:<br>
`config.mk` : *file* - Configuration<br>
`migrate` : *folder* - Migrate Shell scripts<br>
`grub` : *folder* - Grub files<br>

### config.mk<hr>
**Required:**<br>
`ISO_OUTPUT_NAME` - The ISO file name<br>
`CHROOT_PKGS` - Packages that be installed<br>
`DEBIAN_VERSION` - Debian version that be used as the base.<br>
`ARCH` - The architecure ofcourse<br>

**Not required:**<br>
`APT_ARG` - APT install arguments that be appended when installing the `CHROOT_PKGS`<br>
`DEBOOTSTRAP_ARGS` - Debootstrap arguments that be gonna get appended<br>

### Migrate folder
<hr>
Shell scripts is gonna directly run inside the environment.<br>
Its copys the shell script directly and runs it in chroot, then removes it.

### grub folder
<hr>
The grub2 folder, where the grub.cfg is stored.

## Custom Config
#### 1. Create folder in configs with a name like: 'minimal_example'
#### 2. Add a file named config.mk, write the values how [How the config (system) work?](#how-the-config-system-work) describes it.
#### 3. Create a **migrate** and **grub** folder in your config folder, like: **configs/minimal_example**
#### 4. Add a grub.cfg for configuring the grub2.
#### 5. Check everything is right with: 
*(I go with 'minimal_example' for demostrating.)*
```sh
sudo make CONFIG=minimal_example default_checks 
```
#### 6. If everything is okay run the setup:
```sh
sudo make CONFIG=minimal_example setup 
```
When its done you see a "Setup is done, used config: minimal_example" message. <br>
#### 7. Try out commands for configureing and testing: [Commands](#commands)<br>
#### 8. Done? Generate the iso: [Build ISO](#build-iso)
```sh
sudo make CONFIG=minimal_example iso
```
Its writes out the path where its stored.<br>
#### 9. Test, boot, have fun.
You successfully created your config and built it down!<br>
Test your generated iso in VirtualBox, qemu or in any Virtualization environment.

## Commands
All commands are applied to the specified configuration: `CONFIG=[config_name]`

### Setup
Creates the system based on the defined configuration.
```sh
sudo make CONFIG=[config_name] setup
```

### Migration 
Runs the shell scripts located in the config's `migrate` directory in numerical order.  
*(Note: The `setup` command runs this automatically.)*
```sh
sudo make CONFIG=[config_name] migrate
```

### Build ISO
Generates an ISO file named after the `ISO_OUTPUT_NAME` variable defined in your configuration. Once the process is complete, a message will display the output path.
```sh
sudo make CONFIG=[config_name] iso
```
If you only need to rebuild the ISO, run:
```sh
sudo make CONFIG=[config_name] reiso
```

### Chroot 
Opens a Bash shell inside the environment for manual configuration.
```sh
sudo make CONFIG=[config_name] chroot
```

### Checking
Check your configuration is right with:
```sh
sudo make CONFIG=[config_name] default_checks 
```

### Install Packages
Re-runs the package installation step for the selected configuration.
```sh
sudo make CONFIG=[config_name] install_pkgs
```

### Cleaning
Clean commands: `distclean` and `isoclean`<br>

Fully deletes the config generated build enironment. <br>
```sh
sudo make CONFIG=[config_name] distclean
```
Clears the generated iso files.
```sh
sudo make CONFIG=[config_name] isoclean
```
